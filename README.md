###  The Locked Room

## About the Project

The Locked Room is a C++ console-based escape room game that I created as one of my learning projects.

The game is based on a simple idea: the player is trapped inside a locked room by the Evil Puzzle Master and needs to solve different challenges to escape.

To unlock the room, the player has to find a secret five-character code by solving five challenges. Each challenge gives one character of the final code.

##  Game Modes

The game has two modes:

- **Maths Mode:** Solve mathematical questions and number-based problems.
- **Puzzle Mode:** Solve different puzzles, patterns, riddles, and brain teasers.

Both modes lead to the same final goal, but the types of questions and challenges are different.

##  Challenges

The game consists of five challenges:

1. Special Character Challenge
2. Digit Challenge
3. Alphabet Challenge
4. Second Digit Challenge
5. Final Alphabet Challenge

Each challenge helps the player discover one part of the secret code.

##  Features

- Two different game modes.
- Randomly selected questions and puzzles.
- Mathematical and logical challenges.
- Number patterns and brain teasers.
- Multiple attempts to solve challenges.
- Option to switch between game modes.
- Interactive story-based gameplay.

##  Technologies Used

- C++
- Standard C++ Libraries
